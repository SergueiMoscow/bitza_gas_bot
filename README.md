# Gas Bot - Telegram бот для учета газовых баллонов

Бот для учета прихода и расхода газовых баллонов в многоквартирном доме.

## Установка

1. Клонируйте репозиторий
2. Скопируйте `.env.example` в `.env`
3. Заполните настройки в `.env`
4. Запустите: `docker-compose up -d`

## Настройка

Добавьте пользователей в `ALLOWED_USER_IDS` в формате: `123456789,987654321`
